# Windows-12

Это прототип Windows 12 на Node.js 
Мне помогал Claude Opus 5.5, выпито кружек с кофе 3, разработано за 3 дня
Здесь есть очень много функцией, например свой ии помощник, рабочий браузер и т.д

# Как запустить
1. Зайдите в паку Windows 12 по пути: ВАШ_ДИСК\Claude\app\myapp\dist\Windows12
2. Там запустите приложение
3. Пользуйтесь!
